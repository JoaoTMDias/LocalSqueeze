Initial public release of Squeeezer.

- Added browser-based compression for JPEG, PNG, WebP, SVG, PDF, and MP4 files.
- Added lazy SVG optimization with conservative safety options.
- Added PWA installation, offline caching, and update notifications.
- Added responsive compression settings in a Sheet dialog.
- Added compact compression results with accessible action tooltips.
- Improved keyboard navigation, skip links, focus indicators, and semantic markup.
- Added the Squeeezer branding and package version display.
